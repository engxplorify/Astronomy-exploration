🌌 Dark Energy

Measuring Cosmic Expansion with Python

From Type Ia supernova observations to the Hubble constant: connect real redshift-distance data, statistical modeling, and modern cosmology.

Open the project on GitHub ↗

🌌 Project Overview

This project analyzes the Tonry et al. (2003) Type Ia supernova dataset to estimate the Hubble constant, H₀, and quantify its uncertainty.

  • Dataset: redshift and distance-modulus measurements from Type Ia supernovae
  • Physical model: Hubble’s law, v = H₀d
  • Research focus: compare linear fitting, weighted least squares, maximum likelihood, and Bayesian inference

Core idea: turn raw astronomical observations into evidence for the expansion rate of the universe.

✨ Portfolio Highlights

  • Real Type Ia supernova observations from Tonry et al. (2003)
  • A complete data preprocessing and physical-unit conversion workflow
  • Linear and weighted least-squares estimates of H₀
  • Maximum-likelihood modeling with intrinsic scatter
  • Bayesian posterior sampling with 32 MCMC walkers
  • Corner plots and autocorrelation diagnostics for uncertainty analysis

🧠 Physical Context

At low redshift, cosmic expansion can be approximated by Hubble’s law:

v = H₀ d
  • v is a galaxy’s recession velocity
  • d is its distance from Earth
  • H₀ is the present-day expansion rate of the universe

Type Ia supernovae act as standardized candles: brightness gives distance, while host-galaxy spectra provide redshift.

🧪 Analysis Pipeline

Tonry data → preprocessing → visual exploration → weighted fitting → MLE → Bayesian MCMC → posterior diagnostics

  • 1) Read the astronomical table with Astropy
  • 2) Convert distance modulus into distance in Mpc
  • 3) Propagate logarithmic distance uncertainty
  • 4) Inspect velocity versus distance on linear and logarithmic axes
  • 5) Select the low-redshift 0–700 Mpc fitting range
  • 6) Compare statistical estimators and their uncertainty assumptions
# Weighted model
d = m * v + b
H0 = 1 / m

# Bayesian posterior
log P(theta | data) = log P(data | theta) + log P(theta)

📊 Representative Results

The included analysis demonstrates how the inferred Hubble constant changes when measurement uncertainty and intrinsic scatter are modeled differently.

🔭 Why the Estimates Differ

The gap between weighted least squares and MLE/MCMC is scientifically meaningful rather than a failure. Each method makes different assumptions about observational uncertainty and unexplained intrinsic scatter, which changes the inferred cosmological parameter.
